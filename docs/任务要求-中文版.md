评估指导

您的任务是为一个网站创建规格说明文档,并实现一个概念验证网站。


网站设计旨在为需要在互联网技术和实施策略之间进行选择的现实场景提供解决方案。文档必须详细、结构化,并涵盖课堂上讨论的所有指定方面。概念验证将是一个可工作的 Web 应用程序,它展示了网站的设计以及与数据库的一些交互,它不是设计文档的完整实现。
您可以使用任何适当的技术来实现网站,并且不限于使用 Remix 技术栈或 Docker 容器化。不要使用 Microsoft 解决方案或 PHP/Laravel,因为这些在其他模块中有所涵盖。
注意:您的解决方案必须是原创的,代码存储在 GitHub 上,最好部署在互联网上。
a) 两人一组工作
虽然课程作业旨在成对开发,但将接受个人提交,但不会对单独努力给予任何补偿。如果无法进行偶数配对,网站可以由三人开发。


有关概念验证网站场景的详细信息以及报告结构的进一步建议在模块手册中通过 Aula 提供。
